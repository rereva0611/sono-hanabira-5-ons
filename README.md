# 花吻在上5《爱上你的幸福》ONS 移植版

その花びらにくちづけを あなたを好きな幸せ（ふぐり屋，2008）的 ONScripter 移植，补上系列 ONS 1-4、6-10 之间缺失的第 5 作。2026-09 完成，作者 ReReva。

## 下载

前往 [Releases](../../releases) 下载 `花吻5ONS_爱上你的幸福.zip`（约 200 MB），解压即游戏目录（0.txt / arc.nsa / default.ttf / icon.png）。

## 安装

用支持 GBK 中文脚本的 ONScripter 模拟器（ONSPlayer、onsyuri、MINE 等）打开解压出的目录即可，分辨率 800×600。有问题欢迎提 issue。
